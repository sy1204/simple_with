# 📑 프로젝트 기획서: 직장인 올인원 업무 유틸리티 (One-Page)

## 1. 프로젝트 비전

> **"출근과 동시에 열어두고 퇴근 시 닫는, 직장인의 업무 몰입과 개인 편의를 돕는 최고의 웹 도구"**

* 대화형 AI(LLM)보다 빠른 **'직관적 계산'**과 **'업무 흐름'** 중심의 UI 제공.
* 별도의 설치나 가입 없이 URL 접속만으로 즉시 사용 가능.

## 2. 디자인 및 UX 가이드라인 (Stitch 단계)

* **레이아웃**: 원페이지 SPA(Single Page Application) 구조.
* **GNB**: 실시간 시계, 날씨 요약, 3종 테마 스위치.
* **사이드바**: '간단'/'추가' 그룹별 메뉴. 클릭 시 해당 섹션으로 Smooth Scroll 이동.
* **메인**: 카드(Card) 형태의 독립적인 모듈 그리드 배치.


* **테마 시스템 (3-Mode)**:
* **Day**: 화이트 기반의 깨끗한 고대비 테마.
* **Dark**: 저조도 환경을 위한 딥 차콜 테마.
* **Anti-Blue**: 눈의 피로를 최소화하는 따뜻한 세피아/앰버 테마.


* **반응형**: Web(3~4열), Tablet(2열), Mobile(1열)의 균질한 퍼포먼스.
* **스타일**: 미니멀리즘, 12px 라운드, 소프트 섀도우, 직관적인 라인 아이콘 포인트.

## 3. 기술 스택 및 데이터 정책 (Antigravity 단계)

* **Tech Stack**: HTML5, CSS3(Tailwind), Vanilla JavaScript (No Framework 권장).
* **No DB & No LocalStorage**:
* 기업 보안 및 공용 PC 사용 환경을 고려하여 하드디스크에 흔적을 남기지 않음.


* **SessionStorage 전략**:
* **새로고침(F5) 시 데이터 유지**: 업무 중 실수로 페이지를 새로고침해도 입력값 보존.
* **휘발성 보안**: 브라우저 탭이나 창을 닫으면 모든 데이터가 즉시 파기됨.

## 5. 보안 및 안정성 점검 완료 (FAQ)

* **기업 보안**: 표준 Web Storage API(sessionStorage)를 사용하므로 사내 네트워크 보안 정책(DLP 등)에 저촉되지 않음.
* **데이터 유실 방지**: `sessionStorage`를 통해 의도치 않은 새로고침에도 입력 데이터가 안전하게 유지됨을 검증함.
