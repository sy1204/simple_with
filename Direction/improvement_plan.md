## 2. 구조적 개선 사항

### 2.1 네비게이션 메뉴 구조 개선

**현재 상태**: 모든 메뉴가 단일 리스트로 나열됨

**concept.md 요구사항**: 
- 사이드바: '간단'/'추가' 그룹별 메뉴
- 클릭 시 해당 섹션으로 Smooth Scroll 이동

**개선 계획**:
```
[전체보기] | [간단 ▼] | [추가 ▼]
  ├─ 타이머
  ├─ 계산기
  ├─ D-Day (캘린더)
  ├─ 금융 계산
  └─ 단위 변환

  ├─ Todo List
  ├─ 통합 사전
  ├─ 날씨 정보
  └─ 추천 도구 (맛집 검색)
```

**구현 방법**:
1. 네비게이션에 그룹 구분선 또는 드롭다운 추가
2. 각 그룹 클릭 시 해당 섹션으로 스크롤
3. 메인 콘텐츠 영역에 섹션 헤더 추가 (선택사항)

---

### 2.2 SessionStorage 저장 항목 점검

**concept.md 명세**:

| 기능 | 세션 저장 항목 |
|------|---------------|
| 타이머 | 남은 시간, 타이머 가동 여부 |

| D-Day | 이벤트 이름, 목표 날짜 |

| 날씨 정보 | 설정된 지역명 |
| 추천 도구 | 제외 설정 메뉴 |

**점검 필요 사항**:

- [ ] concept.md 명세와 일치 여부 검증
- [ ] 누락된 저장 항목 추가

## 3. 세부 기능 개선 사항

### 3.1 추천 도구 위젯 개선

**현재**: 맛집 검색 위젯 (네이버 지역검색 API)

**개선 방향**:
1. **랜덤 추천 기능 강화**
   - 검색 결과 중 무작위 추천 (현재 구현됨)
   - 상황별 필터 추가 (concept.md 요구사항)
     - 시간대별 (아침/점심/저녁/야식)
     - 가격대별
     - 거리별

2. **메뉴 랜덤 추천 추가**
   - 카테고리 선택 시 해당 카테고리의 메뉴 랜덤 추천
   - 예: "한식" 선택 → "김치찌개", "비빔밥" 등 랜덤 추천

3. **제외 설정 메뉴 저장**
   - sessionStorage에 제외할 메뉴/카테고리 저장
   - concept.md 명세 준수

---

### 3.2 날씨 정보 위젯 개선

**현재**: 기상청 API 활용 (초단기실황, 단기예보)

**concept.md 요구사항**: OpenWeatherMap API 활용, 현재 및 주간 예보

**개선 방향**:

## 4. 우선순위별 개선 계획

### 🔴 높은 우선순위 (구조적 요구사항)

1. **네비게이션 메뉴 구조 개선** ('간단'/'추가' 그룹 구분)
   - 예상 작업 시간: 1-2시간
   - 영향도: 높음 (UX 개선)

2. **SessionStorage 저장 항목 점검 및 보완**
   - 예상 작업 시간: 2-3시간
   - 영향도: 높음 (데이터 유지 보장)

### 🟡 중간 우선순위 (기능 개선)

3. **추천 도구 위젯 개선** (랜덤 추천 강화, 상황별 필터)
   - 예상 작업 시간: 2-3시간
   - 영향도: 중간 (concept.md 명세 완전 준수)

### 🟢 낮은 우선순위 (선택적 개선)

4. **날씨 정보 위젯 개선** (OpenWeatherMap API 추가 지원)
   - 예상 작업 시간: 1-2시간
   - 영향도: 낮음 (현재 API로도 충분히 동작)
